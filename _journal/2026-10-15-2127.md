4h of building

Lots of soldering today, especially for the battery port of the ESC board, which took forever to do because the solder wasn't sticking to the pads. But we finished it anyway and successfully powered up the ESC board, FC, and GPS module using a bench power supply set to 11 V and 0.5 A.

Testing the GPS was pretty fun. We had to move to the very edge of the building floor to get some signal from the satellites. Since sky was still partially covered there, we were only able to make contact with 6 satellites, which is below the recommended 10. Although we did get a 3D fix in Mission Planner and the position in the map was pretty accurate to where we were.

We weren't able to test the RC receiver so we plan on doing that tomorrow as well as testing the motors.
